## Sources CC0 recommandées
- **Freesound.org** (filtre licence = Creative Commons 0) — nécessite une clé API pour le téléchargement automatisé.
- **archive.org** : uniquement les items avec `licenseurl` = publicdomain/zero (⚠️ beaucoup d'uploads non-libres à éviter).
- **selektaudio.com**, **OpenGameArt.org** (CC0).
