DJ Kids transforme votre Hercules DJControl Inpulse 200 MK3 en machine à apprendre le scratch.

APPRENEZ DE VRAIES TECHNIQUES DE SCRATCH
Un curriculum progressif basé sur les vrais gestes des DJs :
• Baby scratch — la base
• Forward, chirp, tear, scribble — niveau intermédiaire
• Transformer, flare, orbit — techniques avancées

COMMENT ÇA MARCHE
Branchez votre MK3 en USB. DJ Kids le détecte automatiquement et mappe chaque bouton, fader et platine. Lancez une session d'entraînement : un breakbeat tourne en boucle, une grille rythmique vous montre exactement quand scratcher, et l'appli score votre précision en temps réel.

DU VRAI MATÉRIEL DJ, DE VRAIS SKILLS
Ce n'est pas un jeu de tap. Vous utilisez la vraie platine pour scratcher, le crossfader pour couper et les boutons EQ pour sculpter le son. Chaque geste appris ici se transfère directement derrière une vraie console DJ.

DEUX PLATINES, TABLE DE MIXAGE COMPLÈTE
En dehors du mode entraînement, vous disposez d'un setup complet 2 platines :
• EQ 3 bandes par platine
• Contrôle pitch/tempo
• Crossfader
• Moniteur MIDI pour vérifier vos mappings

COMPATIBLE AVEC
• Hercules DJControl Inpulse 200 MK3 (USB class-compliant, aucun pilote nécessaire)

CONFIDENTIALITÉ
DJ Kids fonctionne entièrement hors ligne. Aucun compte, aucune collecte de données, aucune connexion requise.
